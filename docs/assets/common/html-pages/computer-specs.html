System Specifications

Laptop requirements for the Software Developer Program. When in doubt, prioritize RAM and storage — they matter more day-to-day than raw CPU speed.

Acceptable Specifications (Minimum)

These are the minimum specifications for running our software and tools efficiently:

  • Processor (CPU): Intel Core i5 (12th gen or newer) or AMD Ryzen 5 (5000-series or newer) — in general, a CPU released within the last 3–4 years
  • Memory (RAM): 16 GB
  • Storage: 512 GB SSD — development tools, container images, and project files fill drives quickly
  • Graphics: Integrated graphics are fine; no dedicated GPU needed
  • Operating System: Windows 11 (Home or Pro) or macOS 14 or newer
  • Display: 14-inch or larger, Full HD (1920×1080)
  • Ports: USB-C and USB-A (an inexpensive hub or dongle covers HDMI/Ethernet needs)
  • Camera & Audio: Working webcam and microphone for collaboration, standups, and remote sessions
  • Networking: Wi-Fi 6, Bluetooth 5.0
  • Battery Life: Enough to get through a class session unplugged; outlets aren't always available

Recommended Specifications

For the smoothest experience across the full program — including capstone work, virtual machines, and AI coursework — aim for:

  • Processor (CPU): Intel Core i7 / AMD Ryzen 7 (current or previous generation), or Apple M-series (M2 or newer)
  • Memory (RAM): 32 GB — strongly recommended if you plan to run local AI models, containers, or multiple virtual machines
  • Storage: 1 TB NVMe SSD
  • Graphics: Integrated graphics remain sufficient; skip the dedicated GPU and put the money toward RAM and storage instead
  • Operating System: Windows 11 or current macOS
  • Display: 15-inch or larger, Full HD or QHD (2560×1440)
  • Ports: Multiple USB-C and USB-A, HDMI
  • Networking: Wi-Fi 6E, Bluetooth 5.2 or newer
  • Other: Backlit keyboard, solid build quality, and a cooling system that stays quiet under load
Why no gaming GPU? Our coursework — web development, application development, and AI — doesn't benefit from a low-end dedicated graphics card. AI work in the program uses cloud services and APIs, where extra RAM helps far more than a laptop GPU.

Mac and ARM Laptops — Read Before Buying

Apple Silicon Macs (M1–M4): Fully supported for this program. All core tools (VS Code, Git, Node.js, Docker, browsers) run natively and well. If a specific course requires Windows-only software, we'll provide alternatives or lab access.

Windows on ARM (Snapdragon laptops): Approach with caution. Most everyday tools now work, but some installers, drivers, and virtualization software still have compatibility gaps. If you already own one, talk to your instructor before the semester starts; if you're buying new, choose an Intel or AMD (x86) machine instead.

Chromebooks and tablets: Not sufficient for this program, even with keyboard attachments.

Questions about a specific machine? Send the model number to your instructor before you buy — we're happy to sanity-check it.
